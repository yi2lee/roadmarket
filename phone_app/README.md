# 로드마켓 폰 앱

중고 거래 서비스 「로드마켓」의 스마트폰 웹 페이지(서버의 `/phone`)를 안드로이드 앱 안에서 그대로 띄우는 껍데기 앱이에요.

## 무엇을 하나요
- 앱을 켜면 `서버 주소 + /phone`을 열어요.
- 로그인은 페이지의 localStorage(`rm_phone`)에 남아서, 앱을 다시 켜도 유지돼요.
- 카카오 로그인 중에 나오는 `intent://`, `kakaotalk://` 주소는 카카오톡 앱으로 넘겨요. 앱이 없으면 대신 열 주소를 앱 안에서 열어요.
- 사진 버튼을 누르면 「사진 고르기」 창에 카메라도 함께 나와요. CAMERA 권한은 받지 않아요.
- 인터넷이 끊기면 「다시 시도」 화면을 보여 줘요.
- 앱이 뒤에 있어도 새 요청·거래 뒤 물음·급구를 알림으로 알려 줘요 (아래 「알림」).

## 알림
- 앱 화면이 `/phone`을 띄우면, 페이지의 로그인 표(`rm_phone`)를 앱 전용 저장소로 옮겨요. 페이지를 열 때, 뒤로 갈 때, 화면이 보이는 동안 3초마다 옮겨요.
- 표가 있으면 앱이 앞에 있을 때 `WatchService`를 켜요. 상태 줄에 「로드마켓이 요청을 기다리고 있어요」가 조용히 떠 있어요.
- 서비스는 5초마다 `GET /phone/state`를 읽기만 해요. 실패가 이어지면 30초까지 늘렸다가, 성공하면 5초로 돌아와요.
- 처음 보는 요청·거래 물음·급구만 알려요. 이미 알린 것은 저장소에 기억해요. 앱 화면이 보이는 중이면 알리지 않아요.
- 요청이 사라지면(수락·거절·취소) 그 알림도 지워요.
- 로그아웃하거나 서버가 표를 거절(401)하면 서비스가 멈춰요.
- 알림 허용은 로그인 뒤 한 번만 물어요. 거절하면 서비스는 돌지만 알림은 안 보여요.

한계
- 앱을 최근 앱 목록에서 밀어 없애거나 강제 종료하면 서비스가 멈춰요. 앱을 다시 열어야 다시 켜져요.
- 폰을 오래 가만히 두면(잠자기 모드) 안드로이드가 묻는 간격을 늘려서 알림이 늦어질 수 있어요.
- 서버가 보내 주는 방식(푸시)이 아니라 앱이 묻는 방식이라 배터리와 데이터를 조금 써요.

## 빌드
```
cd ./phone_app
JAVA_HOME=/opt/homebrew/opt/openjdk@17 /opt/homebrew/opt/gradle@8/bin/gradle -q assembleDebug
```
결과: `app/build/outputs/apk/debug/app-debug.apk`

외부 라이브러리는 쓰지 않아요. 안드로이드 기본 API와 Kotlin 표준 라이브러리만 써요.

## 서버 주소 바꾸기
기본값은 `https://relay-production-68643d09.up.railway.app`이에요. 빌드할 때 `-PserverUrl`로 바꿔요.
```
… gradle -q assembleDebug -PserverUrl=http://10.0.2.2:8099
```

서버 주소를 바꿔서 빌드할 때는 `clean`을 먼저 해요. 안 하면 옛 주소가 앱에 남아요(실제로 겪었어요).

```bash
… gradle -q clean assembleDebug -PserverUrl=…
```
- http 주소는 디버그 빌드에서 `10.0.2.2`, `localhost`, `127.0.0.1`만 열려요 (`app/src/debug/res/xml/network_security_config.xml`).
- 출시 빌드는 https만 열려요.
