# 로드마켓 (RoadMarket)

달리는 동안 내 차가 가게가 되고, 기다림 없이 지금 길 위에서 살 수 있는 중고거래 플랫폼입니다.

현대자동차그룹 차량용 앱 개발 공모전 출품작이며, Pleos Connect 환경에서 동작합니다.

시연 영상: https://www.youtube.com/playlist?list=PLJmxULw_JW68

## 무엇을 하나요

| 단계 | 하는 일 |
|---|---|
| 등록 | 스마트폰이나 차량 화면에서 물건과 찾는 키워드를 올립니다. 다른 중고 거래 앱에 올린 물건은 링크나 캡처로 등록합니다. 주행 중에는 말로 등록합니다 |
| 발견 | 가던 길에서 10분 안에 닿는 물건을 보여 주고, 키워드와 맞는 물건이 나타나면 읽어 줍니다 |
| 성사 | 구매자가 거래를 요청하고 판매자가 수락하면 거래가 정해집니다. 급하게 필요한 물건은 구매자가 먼저 주변에 요청합니다 |
| 만남 | 두 사람이 가장 덜 돌아가는 편의점, 주유소, 주차장을 만날 곳으로 정해 내비게이션에 넣습니다. 지도에 상대 위치와 도착 시간이 보입니다 |
| 완료 | 거래 결과를 묻고 서로 별점을 줍니다 |

## 구성

| 폴더 | 내용 |
|---|---|
| `app/` | 차량 앱. Kotlin, Pleos Connect(Android Automotive) |
| `server/` | 서버와 스마트폰 웹 화면. Python 표준 라이브러리만 사용 |
| `phone_app/` | 스마트폰 웹 화면을 담은 안드로이드 앱 |
| `docs/` | 기능 요건표, 화면별 데모 둘러보기 |
| `apk/` | 설치 파일. 차량 앱과 스마트폰 앱의 디버그 빌드 |

차량 앱은 1초마다 현재 위치, 내비 목적지, 주행 여부를 서버에 보내고, 서버는 주변 물건, 들어온 요청, 만날 곳을 돌려줍니다.

## 사용한 Pleos SDK

| SDK | 쓰는 곳 |
|---|---|
| NaviHelper SDK | 현재 위치와 목적지 읽기, 만날 곳을 경유지로 넣기 |
| Vehicle SDK | 기어로 주행 여부 판단, 운전석 문으로 하차 감지 |
| TextToSpeech SDK | 거래 요청과 알림 읽어 주기 |
| Gleo Interface (App Schema) | 음성 명령 3종: 물건·키워드 등록, 거래 요청·수락, 주변 물건 조회 |

외부 API는 카카오 로컬, 카카오모빌리티 길찾기, 카카오 로그인, 카카오 지도를 씁니다.

## 실행

### 서버

```
cd server
python3 server.py
```

포트는 환경 변수 `PORT`, 없으면 8099입니다. 스마트폰 화면은 서버 주소 뒤에 `/phone`을 붙여 엽니다.

카카오 키는 저장소에 들어 있지 않습니다. 환경 변수나 `server/.env`로 넣습니다. 필요한 이름은 `server/README.md`에 있습니다. 키가 없으면 만날 곳은 시연용 장소로 정해집니다.

### 차량 앱

Pleos Connect 에뮬레이터에서 실행합니다. JDK 17과 Gradle 8이 필요합니다.

```
cd app
gradle assembleDebug -PserverUrl=http://10.0.2.2:8099
```

에뮬레이터 두 대로 거래를 돌려 보는 순서는 `docs/데모_둘러보기.md`의 "다시 실행하는 법"에 있습니다. `app/demo.sh`가 그 명령들을 묶어 둔 스크립트입니다.

### 스마트폰 앱

```
cd phone_app
gradle assembleDebug -PserverUrl=http://10.0.2.2:8099
```

## 알아 둘 점

- 경로 추천과 드라이브 코스는 시연용 경로 데이터로 동작합니다.
- 스마트폰 쪽 알림은 화면을 열어 두었을 때 보입니다.
- 자세한 화면과 동작은 `docs/데모_둘러보기.md`, 기능별 요건은 `docs/기능요건.md`에 있습니다.
